## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## CMS

Read docs/cms/INTEGRATION.md before working on the CMS integration.

- `docs/cms/` is generated by `npm run cms:docs` (see CMS-DOCS-SETUP.md). Never edit files there; the updater stops on local edits.
- The site imports the generated client, types and rich-text renderer directly from `docs/cms/`, so refreshing the docs updates the integration. Run `npx astro check` afterwards to catch schema changes.
- Production is fully static: CMS content is fetched during `astro build`, and media links to stable CMS asset URLs. Content changes require a fresh build and deployment; there is no runtime revalidation endpoint. See README.md for Coolify settings.
- Website code for the CMS lives in `src/lib/cms.ts` and `src/lib/routes.ts`.
